## 2. SOC Analyst (Networking)

### Concepts Learned
- **OSI 7-Layer Model:** Physical, Data Link, Network, Transport, Session, Presentation, Application.
- **TCP/IP 4-Layer Model:** Network Access, Internet, Transport, Application.
- **Encapsulation:** Data $\rightarrow$ Segment $\rightarrow$ Packet $\rightarrow$ Frame $\rightarrow$ Bits.
- **Addressing:** MAC Addresses (Layer 2 - Hardware) vs. IP Addresses (Layer 3 - Logical).

### Key Takeaways / Port Numbers
- **Layer 2 (Data Link):** Frame, MAC Address, Switch.
- **Layer 3 (Network):** Packet, IP Address, Router.
- **Layer 4 (Transport):** Segment, TCP/UDP, Port Numbers.
